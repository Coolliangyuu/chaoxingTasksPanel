学习通作业看板 · 版本日志
按版本从新到旧排列

1.4.10
- Windows x64 单文件发布启用压缩，减少 EXE 下载体积。
- 超过截止时间仍未提交的作业显示「已截止，未提交」，默认与待批阅、已完成的作业一起按截止时间排列。
- 提交状态正序为未提交、已截止未提交、待批阅、已完成，再点一次反转顺序。待处理只统计尚未截止的作业。
- 原先显示「未知」的距离截止改为「已截止」，保留网页明确提供的其他时间状态。
- 主窗口加宽 100 像素，增加截止时间和提交状态列宽。鼠标悬停时高亮整行，移开后恢复。
- 作业列表启用双缓冲。快速移动鼠标时只重绘高亮发生变化的两行，减少闪烁和卡顿。
- 修复主窗口右上角账号姓名被裁切的问题。账号区域根据文字和窗口宽度自动调整，较长的姓名可以换行显示。
- 右下角新增「设置」，可以查看版本日志，也可以选择 GitHub 或 Gitee 检查正式版更新。选择的更新源会保存。

1.4.9
- 每个作业详情都是独立窗口，在 Alt+Tab 和任务栏预览中按作业标题分别显示。
- 查看日志和账号管理仍作为主窗口上的弹窗。退出应用时会关闭所有作业详情窗口，退出单个账号时会关闭该账号的作业详情窗口。

1.4.8
- 看板右下角新增「查看日志」。弹窗支持滚动查看和复制完整版本记录。
- 版本日志随 exe 内置，与发布的 TXT 内容一致。

1.4.7
- 新增青色作业纸和暖金色时钟组成的应用图标。exe、任务栏和应用窗口使用同一图标。
- 内置多种图标尺寸，适配小尺寸标题栏和大尺寸资源管理器视图。

1.4.6
- 点击「作业」表头恢复默认排序，并清除当前排序箭头。
- 作业详情里的附件下载会打开 Windows 保存窗口，可选择文件名和保存位置，并显示保存结果。
- 新开窗口的附件沿用当前账号会话，保留原作业页面。兼容浏览器生成的附件、超星云盘附件和网页触发的下载。
- 支持在同一作业页面连续下载附件，每个文件分别选择保存位置。

1.4.5
- 「提交状态」表头支持按未提交、待批阅、已完成排序，再点击一次反转顺序。
- 「截止时间（北京）」和「距离截止」表头可按实际截止时间从早到晚或从晚到早排序。截止未知的作业排在末尾。
- 表头箭头标明当前排序方向。刷新作业或切换筛选后保留当前排序。

1.4.4
- 作业看板、账号管理、永久登录设置和作业详情窗口的默认宽度、高度各增加 100 像素。

1.4.3
- 把「点击修改」移入「已配置永久登录」的青色按钮，作为第二行小字。点击按钮任意位置均可打开修改设置。
- 按实际字宽分配按钮空间，修复较大系统字体下账号操作按钮文字被截短的问题。

1.4.2
- 修复账号管理列表中，已配置永久登录的账号行裁切按钮、登录状态和「点击修改」的问题。
- 统一账号行的高度和按钮位置，为「点击修改」保留独立空间。

1.4.1
- 已启用永久登录的账号显示「已配置永久登录」，下方提供「点击修改」。保存或关闭设置后，账号列表就地更新。
- 优先沿用学习通已有的登录会话。仅在会话失效时，才使用已保存的凭据尝试重登。
- 自动重登先勾选并确认超星官方的「下次自动登录」，再填入账号密码并提交。如果网页无法确认已勾选，则交由用户手动登录。
- 修复退出账号后账号管理窗口自动关闭的问题。退出成功后在当前窗口移除该行，其他账号仍可继续操作。

1.4.0
- 在「切换到此账号」左侧新增「永久登录」。可为单个账号保存账号密码、修改设置或关闭自动重登。
- 检测到登录失效后，使用超星官方密码登录页填写并尝试重新登录。验证码、滑块或其他验证由用户手动完成。
- 账号密码由本机 Windows 凭据管理器保存。关闭自动重登或退出该账号时清除对应凭据。

1.3.0
- 登录后从超星账号管理页自动读取姓名和脱敏手机号。添加账号时省去手动备注。
- 启动时后台检查各账号。显示未登录、仅本次会话、会话保留期限或暂时无法确认。
- 每行右侧新增独立的「切换到此账号」和「退出此账号」按钮。添加入口统一显示「添加账号」。
- 修复退出后账号仍留在列表的问题。退出后移除该账号，全部退出后显示空列表。

1.2.0
- 新增账号管理，可以添加、切换并单独退出学习通账号。
- 每个账号使用独立的浏览器会话。超星的「下次自动登录」可在有效期内保留会话。
- 记录账号备注和当前所选账号。作业窗口与打开它的账号绑定。

1.1.1
- 把「查看详情」改成每行最右侧的独立按钮。倒计时移到按钮左边，其余列向前收紧。

1.1.0
- 新增作业详情弹窗。单击作业行，在独立窗口打开学习通作业详情。
- 优先打开学习通桌面网页版作业界面，沿用看板的登录会话。

1.0.1
- 修复读取截止时间时发生格式转换错误、导致「立即刷新」后整个看板空白的问题。
- 统一截止时间的传递格式。超过一天的倒计时显示到分钟。

1.0.0
- 首次发布 Windows 作业看板。汇总学习通作业、课程、提交状态、北京时间截止时间和倒计时。
- 支持按全部作业、待处理、已完成和状态待确认筛选。看板每 5 分钟自动刷新，也可点击「立即刷新」。
- 内置超星官方登录页，支持账号密码、短信验证码、扫码和机构登录。需要额外验证时显示官方控件。
- 启动和刷新时检查登录状态，分别提示需要登录、登录失效或暂时无法检查。
